# Anchor v0.1.0 — Beta

First beta build of Anchor, a local-first personal project manager. Everything lives on your own machine — projects, kanban boards, notes, canvases, and a home-page to-do list — with no account and no hosted backend.

## What's in this build

- **Home** — actionable overview: needs-attention/stale-project nudges, status breakdown, points trend, recent notes, and a standalone to-do list
- **Projects** — list/grid views, sort/filter by priority/status/due date, progress bars
- **Kanban boards** — per-project columns, drag-to-reorder, points, priority, due dates
- **Notes** — WYSIWYG markdown editor, standalone or project-linked, stored as real `.md` files in your vault folder
- **Canvas** — flowchart/diagram boards (shapes, connectors, colors), standalone or project-linked
- **Recycle bin** — soft delete with 30-day auto-purge, across projects/cards/notes/canvases
- **Multi-vault support** — switch between fully separate datasets (e.g. personal vs. work)
- **Vault export** — Settings → back up your whole vault as a zip
- Motion and sound throughout — this is the part we care about most, so tell us if anything feels off

## Install

Download the installer for your platform below and run it. No account, no sign-in — pick or create a vault folder on first launch.

**You'll likely see a security warning** — this build isn't code-signed yet (that costs a certificate, planned before v1):
- **Windows:** SmartScreen may say "Windows protected your PC." Click **More info → Run anyway**.
- **Mac:** Gatekeeper will block a normal double-click. Right-click the app → **Open**, then confirm.

This is expected and not a sign anything's wrong.

## Where your data lives

Everything is stored inside the vault folder you choose on first launch — nothing goes anywhere else. Back it up anytime by copying that folder, or via **Settings → Export vault as zip**.

## Known limitations (beta)

- Canvas doesn't have sound feedback on connector actions yet — everything else does
- No auto-update yet — new versions mean downloading and reinstalling manually (Settings → About has a "Check for Updates" link)
- Kanban card detail is still a side panel, not a full expanded note view
- Visual redesign direction is still being explored — current look isn't final

## Found a bug?

Please [open a GitHub issue](https://github.com/rileyheasley/anchor/issues/new) — include what you were doing, your OS, and if you can, attach the log file from **Settings → About → Open log folder** (`anchor-errors.log`).

Thanks for trying it out.
